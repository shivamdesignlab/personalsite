Transfer Learning in an Educational Parallel Programming Game

January 2023 – May 2024

Overview

This project investigates transfer learning outcomes in Parallel X, an NSF-funded educational game designed to teach parallel programming and concurrency concepts to computer science students. By analyzing how students transfer problem-solving strategies from game-based learning to real programming tasks, we evaluate the pedagogical effectiveness of game mechanics designed to scaffold understanding of complex computational concepts like threading, synchronization, and deadlock prevention.

Research Objectives

  1. Evaluate transfer learning from game-based to traditional programming contexts
  2. Analyze game mechanic effectiveness for teaching concurrency concepts
  3. Measure student engagement and learning outcomes across study conditions
  4. Provide design recommendations for educational programming games

Methodology

Controlled experimental study with pre/post assessments, think-aloud protocols during gameplay, and coding task performance evaluation. Quantitative analysis of learning gains paired with qualitative analysis of problem-solving strategies.
